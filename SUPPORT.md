# Support

## Getting Help

- **Bugs**: Open an [issue](https://github.com/qa-kit-cli/qa-kit/issues/new?template=bug_report.md)
- **Feature requests**: Open an [issue](https://github.com/qa-kit-cli/qa-kit/issues/new?template=feature_request.md)
- **Questions**: Use [GitHub Discussions](https://github.com/qa-kit-cli/qa-kit/discussions)
- **Docs**: [qa-kit.dev/docs](https://qa-kit.dev/docs)

## Scope

We support the current release (`v0.4.0`) and the one prior. Older releases are not actively maintained.

## Response time

Issues and PRs are reviewed on a best-effort basis. Critical bugs (P0) are prioritised.
